## Market mechanism

- Parimutuel: house is escrow, players pay players, pool ratio = live odds. No LP to drain. ~3–6h.
- AMM/LMSR under an information leak: LVR literature — "when all trades against the AMM are generated by informed arbitrageurs, liquidity provision exposes the LP exclusively to adverse selection." (paradigm.xyz/writing/pm-amm, arxiv.org/html/2607.17428). **Rejected.**
- LMSR max loss = `b·ln(n)` (arxiv 1206.5252). Gnosis LMSR uses `Fixed192x64Math` with overflow ceiling ~133·ONE. 2–4 days. Rejected.
- Reference parimutuel fork: `SivaramPg/evm-simple-prediction-market-contract` (MIT, ~680 LOC, binary only, `NoOpposition` revert instead of refund, dust stays in contract).
- Gnosis CTF (`gnosis/conditional-tokens-contracts`, LGPL) for split/merge if ever needed. Polymarket = hybrid CLOB (`Polymarket/ctf-exchange`), not applicable.

## Confidential compute

- **ZK adds nothing** over a hash commitment for "reveal matches commit." zkML (prove which model produced output) is open research. Dropped.
- **TEE does not hide prompts from the API you call.** TLS terminates at OpenAI/OpenRouter/MiniMax. Confidential *text* inference exists (Phala `inference.phala.com/v1`, NEAR AI Cloud); confidential *video* does not.

- Under B-long the only real secret is the unreleased branch videos. tlock does that free; a TEE does it for the prize.

The measure is a crude 64×36 grayscale mean-absolute-difference, not optical flow: it separates "lots
of pixels changing fast" from "almost nothing changing" and nothing finer.

The one artefact on both clips: **on-screen text renders as gibberish** — hoarding sponsors read

why the authoring rules allow graphics as broadcast furniture but forbid anything that depends on
reading them. Appending "No captions, no logos." to `STYLE_SUFFIX` (as `keyArtPrompt` already does)
might suppress it — **untested**, deliberately not applied.
